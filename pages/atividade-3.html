Como iniciar um bom projeto web

  1. Defina a ideia = Qual problema o sistema resolve?

  2. Levante os requisitos = Separe em Requisitos funcionais e não funcionais

  3. Planeje as telas = Use o papel para planejar ou FIGMA

  4. Escolha a arquitetura = Defina as tecnologias e linguagens usadas

  5. Crie uma estrutura organizada = Organize as pastas

  6. Crie o Git desde o início = Evite commits enormes

  7. Faça o README = Documente o projeto

  8. Faça primeiro o layout = Defina cores, botões, cards, responsividade, footer e etc

  9. Desenvolva por funcionalidade = Não foque em terminar o front primeiro, faça LOGIN -> front, back, banco, testar

  10. Modele o banco = Pense nas entidades e defina os relacionamentos

  11. Pense em segurança desde o início =
    • Nunca guardar senha em texto puro
    • Validar dados recebidos
    • Controlar permissões
    • Proteger endpoints
    • Evitar expor informações sensíveis
    • Validar entradas do usuário

  12. Teste constantemente = Não deixe para testar só quando terminar.

  13. Teste a responsividade = Abra o navegador e teste diferentes tamanhos.

  14. Configure o deploy = Assim você terá um projeto que pode ser acessado pela internet.
